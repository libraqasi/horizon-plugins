# Source boundaries

## Horizon-owned identity

The independent HB icon, standalone Horizon Bank wordmarks, `horizon-*` token names, and starter assets in this skill are the approved identity for Horizon prototypes.

Do not copy another bank’s name, initials, logo, wordmark, transport mark, font family name, selector prefix, file prefix, screenshot, customer data, rates, disclosures, or product claims into Horizon output.

## Reusable supporting assets

The bundled utility icons and seven stock photographs were supplied for authorized Horizon design work. Use them only when they fit the task, preserve their aspect ratio and accessibility treatment, and do not imply that a pictured person is a real customer.

## Guidance status

- Exact Horizon colors, logos, and token names in this skill are supplied project guidance.
- Component sizes, spacing, radii, shadows, breakpoints, motion recipes, DOM patterns, and CSS examples are web implementation guidance rather than universal platform requirements.
- The bundled automated audit validates supported web source only. Cross-platform identity and safety guidance may still be useful elsewhere, but native implementation and source validation require the target platform's own conventions and tools.
- Legal, compliance, privacy, security, trademark, and accessibility approval remain separate review gates.
- Never claim live payment/network connectivity or protocol certification without evidence.
