# Horizon Bank Cash Delivery Preview

A mobile-first click-through prototype for exploring a cash-delivery request,
review, confirmation, cancellation, and delivery-status journey. All account,
address, balance, and delivery details are synthetic. The app has no backend and
does not move money or connect to a drone service.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Use `npm run build` to create a production
bundle in `dist/`.

## Synthetic data

The preview uses one deterministic `everyday-banking` customer generated by the
marketplace's `horizon-bank-synthetic-data-generator` plugin. The canonical
bundle and manifest live under `synthetic-data/canonical/`; React consumes only
the privacy-minimized fixture in `src/data/`.

From this directory, regenerate and verify the data with:

```bash
npm run data:config
npm run data:generate
npm run data:adapt
npm run data:validate
npm test
```

The generated account is immutable reference data. The app stores only the
versioned delivery selection and preview status in `localStorage`; it never
posts a transaction or changes the generated balance.

The source imports the Horizon Bank wordmark, fonts, delivery photography, and
icons from the canonical `plugins/horizon-bank-design/` directory. Keep the app
inside this marketplace repository so those relative asset imports remain valid.
